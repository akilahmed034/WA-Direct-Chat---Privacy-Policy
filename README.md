Privacy Policy

## Bulk Sender Marketing Tool

This Privacy Policy explains how Bulk Sender Marketing Tool handles user data.

━━━━━━━━━━━━━━━━━━━━━━
🔒 DATA COLLECTION
━━━━━━━━━━━━━━━━━━━━━━

DirectChat Bulk Sender Marketing does **not collect, store, or share any personal data**.

We do not require any user registration or login to use the app.

━━━━━━━━━━━━━━━━━━━━━━
🚫 INFORMATION WE DO NOT STORE
━━━━━━━━━━━━━━━━━━━━━━

We do NOT store or collect:
• Phone numbers
• Messages
• Chat history
• Contacts
• Media files
• Any personal communication data

All actions are performed locally on your device.

━━━━━━━━━━━━━━━━━━━━━━
📲 HOW THE APP WORKS
━━━━━━━━━━━━━━━━━━━━━━

This app helps you open chats and perform bulk messaging actions by redirecting you to installed messaging applications on your device.

Messages are always sent through your chosen external messaging app, not through our servers.

━━━━━━━━━━━━━━━━━━━━━━
♿ ACCESSIBILITY SERVICE USAGE
━━━━━━━━━━━━━━━━━━━━━━

This app uses Android Accessibility Service **only with user permission** to support bulk messaging automation features.

The Accessibility Service is used strictly for:
• Performing user-triggered message sending actions
• Navigating screens inside the selected messaging app
• Supporting bulk messaging workflow initiated by the user

We do NOT use Accessibility Service to:
• Collect personal data
• Read private messages
• Track user behavior
• Access information outside the messaging process

Users can enable or disable Accessibility Service anytime in device settings.

━━━━━━━━━━━━━━━━━━━━━━

This app does not send data to any external servers.

It may open third-party messaging applications depending on user selection. These apps are governed by their own privacy policies.
